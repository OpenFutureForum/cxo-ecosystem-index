# CXO Ecosystem Index Roadmap

## Completed

- Canonical entity, source, fact, and relationship schemas
- Deduplicated source registry and stable source aliases
- Sourced relationship graph with explicitly derived inverse edges
- Traceable intelligence metrics with cohort, numerator, unknown, and excluded entity IDs
- Machine-readable entity, source, fact, relationship, graph, taxonomy, and search exports
- Validation for identity, evidence references, numeric facts, currencies, dates, and graph integrity

## In progress

- Expand direct evidence for ownership, subsidiary, partnership, and investment relationships
- Apply field-specific staleness review queues across the full dataset
- Increase structured quantitative fact coverage without inferring unknown values

## Next

- Publish taxonomy hierarchy and redirect history
- Add change-level provenance and review ownership
- Add longitudinal snapshots for volatile facts and derived metrics

## Later

- Public contribution workflow with evidence review
- Graph exploration and API query interface
- Automated source-change monitoring with human approval
